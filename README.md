# Care Transition Efficiency & Placement Outcome Analytics

**Internship Project – Project 2**
**Organization:** Unified Mentor
**Project Domain:** Data Analytics & Visualization
**Project Type:** Internship Project

## About the Project

This project was developed as part of my **Unified Mentor Internship**. The objective is to analyze aggregate data related to the Unaccompanied Alien Children (UAC) care pipeline and build an interactive dashboard for exploring apprehension, transfer, care-load, and discharge trends.

The project uses Python, Pandas, Streamlit, and Plotly for data cleaning, exploratory data analysis (EDA), visualization, and interactive reporting.

## Internship Project Objectives

* Perform data cleaning and preprocessing.
* Conduct Exploratory Data Analysis (EDA).
* Analyze trends in apprehensions, transfers, and discharges.
* Develop an interactive dashboard using Streamlit.
* Visualize operational indicators and potential bottlenecks.
* Present findings through charts, KPIs, and filtered data downloads.

## Tools and Technologies

* Python
* Pandas
* Streamlit
* Plotly
* Jupyter Notebook

## Project Deliverables

* Cleaned dataset
* Data cleaning and EDA notebook
* Interactive Streamlit dashboard

* Project demonstration video

## Internship Learning Outcomes

Through this project, I gained practical experience in data preprocessing, exploratory data analysis, data visualization, dashboard development, and presenting analytical findings.

**Note:** This project is intended for educational and exploratory analysis. The dashboard presents aggregate reporting indicators and does not establish individual waiting times or verified placement outcomes.
